# Changelog

## 1.0.0
- Roles and permissions: built-in `user`, `operator`, `admin`, `superadmin` plus custom roles (level, color, per-command permissions, prop limit), editable in the menu.
- Admin menu (`!menu` / F10): players, bans, announcements, journal, reports, roles. English and French.
- Commands: kick, ban/unban, mute, freeze, god, slay, hp, goto, bring, send, setgroup, announce and more (`!help`).
- Action journal with player filter, warnings with automatic kick/ban, player reports, votes (`!vote`, `!votemap`, `!votekick`).
- Role prefixes and colors in chat, on-screen announcements, roleplay chat (`/me`, `/do`, `/ooc`, `/w`, `/s`, `/pm`), optional proximity chat.
- Optional Discord webhook for admin actions.
- Optional link with Modern Props Menu: roles decide who can spawn objects or equip models, with a per-role limit.
